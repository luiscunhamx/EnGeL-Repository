# GHS pictograms

The nine hazard pictograms of the Globally Harmonized System (GHS / EU CLP), as SVG files from Wikimedia Commons (public domain).

| Code | File | Name |
|:--|:--|:--|
| GHS01 | GHS-pictogram-explos.svg | Exploding bomb |
| GHS02 | GHS-pictogram-flamme.svg | Flame |
| GHS03 | GHS-pictogram-rondflam.svg | Flame over circle |
| GHS04 | GHS-pictogram-bottle.svg | Gas cylinder |
| GHS05 | GHS-pictogram-acid.svg | Corrosion |
| GHS06 | GHS-pictogram-skull.svg | Skull and crossbones |
| GHS07 | GHS-pictogram-exclam.svg | Exclamation mark |
| GHS08 | GHS-pictogram-silhouette.svg | Health hazard |
| GHS09 | GHS-pictogram-pollu.svg | Environment |

Use in a protocol header: `ghs: [GHS02, GHS07]`. Pictograms are taken from the safety data sheets (section 2) of the chemicals used, never inferred.
